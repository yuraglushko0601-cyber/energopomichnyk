# ЕнергоПомічник — модуль оновлення цін (v0.7)

1. Отримайте **дозвіл** продавця та URL його структурованого HTTPS JSON-фіда.
2. У `sources.json` замініть приклад, заповніть дозволені домени та встановіть `enabled: true`.
3. Фід має містити масив `offers` з `brand`, `model`, `sku`, `shop`, `url`, `priceUah`, `availability` (`in_stock`, `out_of_stock`, `preorder`, `unknown`). Назва моделі має точно збігатися з каталогом у HTML.
4. Запустіть `python update_prices.py`. Якщо джерело недоступне, попередній знімок зберігається, щоб не публікувати порожній каталог.
5. Для щоденного запуску завантажте проєкт до GitHub; workflow запускається щодня о 05:17 UTC. GitHub Actions не гарантує точний час запуску. Для автоматичного коміту потрібні дозволи на запис у репозиторій.
6. Опублікуйте HTML і `offers.json` в одному каталозі на статичному хостингу (наприклад, GitHub Pages), щоб браузер міг отримувати оновлення. Локальний `file://` режим може блокувати `fetch`, тому ручний імпорт залишається резервним способом.

**Не реалізовано:** інтеграція з реальним магазином, бо немає підтвердженого API/фіда та дозволу. Скрапінг сторінок без погодження не використовується. Ціни не є актуальними, поки не підключено дозволений фід. Дані модифікацій зіставляються за SKU та точними назвами.
