# Публікація ЕнергоПомічника на GitHub Pages

1. Увійдіть на https://github.com і створіть **публічний** репозиторій `energopomichnyk` (без README та шаблонів).
2. Розпакуйте ZIP. **Завантажте в корінь репозиторію вміст папки `energopomichnyk_deploy`, а не саму папку.** Важливо зберегти приховану папку `.github/workflows`.
3. Найзручніше завантажити всю папку через GitHub Desktop: File → Add local repository → Create a repository here → Publish repository. Або завантажити файли через вебінтерфейс GitHub, зберігши вкладені каталоги.
4. У репозиторії відкрийте **Settings → Pages → Build and deployment → Source: GitHub Actions**.
5. У вкладці **Actions** перевірте запуск `Deploy EnergoPomichnyk to GitHub Pages`. За потреби відкрийте workflow і натисніть `Run workflow`.
6. Після успішного деплою сайт буде за адресою `https://ВАШ-ЛОГІН.github.io/energopomichnyk/`. Реальна адреса залежить від вашого логіна GitHub. GitHub може вимагати підтвердження дозволів для Actions.
7. Перевірте на сайті калькулятор, каталог і кнопку «Оновити з сервера». Поки `sources.json` не містить дозволених активних фідів, `offers.json` залишається порожнім, а актуальні ціни автоматично не з'являться.

**Безпека:** репозиторій публічний, тому не додавайте токени API, паролі чи персональні дані. Якщо продавець надасть токен, зберігайте його в GitHub Actions Secrets та адаптуйте модуль для його використання.

**Важливо:** GitHub Pages — статичний хостинг. `update_prices.py` виконується через GitHub Actions, не як постійний сервер. Workflow оновлення вже включений, але він не отримає реальні ціни без дозволених джерел.
